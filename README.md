# Website Profil Kelurahan Pasar Melintang

Website resmi untuk Kelurahan Pasar Melintang sebagai proyek KKN individu.

## 🚀 Fitur
- Desain modern dan responsif
- Animasi halus (fade, slide, zoom)
- Navigasi mobile-friendly
- Informasi lengkap: profil, struktur, layanan, kontak
- Google Maps terintegrasi
- Back to top button

## 🛠️ Teknologi
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- Font Awesome Icons
